关于《团子去旅行》

《团子去旅行》是一款在浏览器里慢慢过日子的静态小游戏。小团子会按作息睡觉、煮饭、浇花、钓鱼、看书，雨天撑伞；点一点它，它会向你挥手。

时间、季节与天气

时钟采用真实的 Asia/Shanghai 时间，右上角显示时刻、季节与天气；默认 ×1 速度，可切到 ×10、×60。春 3–5 月、夏 6–8 月、秋 9–11 月、冬 12–2 月，晴、雨、雪会改变窗外景色与团子的活动。

房间、菜园与商店

下方有七个小标签：小屋、池塘、庭院、商店、行囊、日记、相册。小屋含客厅、读书角、厨房、阳台、池塘、门廊六个房间，可左右切换和拖动家具布置。三叶草是货币：在庭院点击草叶收集，约十分钟长回，偶尔出现幸运四叶草。

阳台的四个花盆可种罗勒、番茄、胡萝卜和草莓，作物按真实时间生长。收成能在厨房做成番茄罗勒便当、胡萝卜饭团盒或草莓果酱面包。商店出售食物、种子、护身符和家具，护身符会影响旅行方向或带回的三叶草。

行囊、旅行与朋友

在行囊选一份食物（必需）和一个护身符（可选），团子会在合适的时候自己出发，旅程约 1–6 小时。不同食物通向森林旧车厢、小镇早市、海边灯塔、蘑菇森林、山顶观测台等地。回家后信箱会出现明信片、纪念品与三叶草；访客朋友不定期来串门，见面三次可留下合照。

日记、相册与存档

日记记录每天的小事，相册收藏去过的地点、明信片和合照。进度只保存在当前浏览器的 localStorage 里：刷新不丢，换设备或清除数据会重新开始，也不同步到服务器。

3D 锦鲤池、广告与本站

点开「池塘」标签，可在画面中看 3D 锦鲤池 /koi/。它由 three.js 构建，有游动的锦鲤、可拖动的视角、白天/黄昏/夜晚光线和投喂互动，手机上也能全屏观看。

三叶草不够时，商店会提供自愿观看的奖励广告，每天最多五次；没有横幅广告，也没有自动播放的广告。

整个游戏是一张静态 HTML 页面，无需安装或构建，美术由手绘与 AI 辅助完成，源码公开在 GitHub 上。

另一个 3D 画廊 /3d/ 用同一个提示词，比较不同 AI 模型搭建的 three.js 场景。

怎么玩

  1. 看看团子此刻在做什么；点它会挥手。
  2. 去庭院收集三叶草，在商店买食物和种子。
  3. 在阳台播种，回来收获；厨房能把收成做成便当。
  4. 去行囊挑食物和护身符，等团子出发。
  5. 回家后读信箱，把明信片收进相册，再去池塘喂锦鲤。
  6. 用日记回看每天的小事；进度只保存在当前浏览器。
