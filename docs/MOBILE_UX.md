# 手机端交互规格

给 P0-11–P0-17 和相关任务用的实现规格。原文在 [research/muse-simplify-mobile-2026-11.md](research/muse-simplify-mobile-2026-11.md)。基线是 2026-11-04 的 390×844 实机截图：[research/mobile-baseline-2026-11.jpg](research/mobile-baseline-2026-11.jpg)（从左到右：家、庭院、池塘、商店、行囊、日记、相册）。

先改信息架构，再做 Capacitor 套壳。底部不要在现有 7 个标签外面再叠一层导航。

## 基线与目标

以草地 8/8 成熟、要出发一次来计，现在的路径是：

Garden → 点 8 片三叶草 → Shop → 买食物 → 买护符 → Bag → 选食物 → 选护符 → Pack。

合计 **16 次点击、3 次切页**，还不含滚动找商品和点错。回家后看明信片、日记、相册还要再跳 3–5 次。

改完后的常规出发：

1. 一键收取
2. 点首页主按钮，打开确认层
3. 「就这样出发」

合计 **3 次点击、0 次切页**。自己改组合最多 5 次。回家再出发是 4 次：点通知或首页包裹 → 收下全部 → 再来一次 → 出发。

省掉的是找按钮和重复点选。出发确认、护符取舍、扣三叶草、装饰摆放仍然要玩家亲手做。

## 信息架构

四个底部 Tab：

| Tab | 中文 | English | 里面有什么 |
| --- | --- | --- | --- |
| 家 | 家 | Home | 客厅、读书角、厨房、阳台、庭院、门廊。左右滑切换。采三叶草在庭院场景里完成 |
| 出行 | 出行 | Trip | 原来的商店和行囊。上半选行囊，下半补给 |
| 池塘 | 池塘 | Pond | 池塘场景，里面一枚主按钮进入全屏 3D 锦鲤池 |
| 收藏 | 收藏 | Keepsakes | 页内分段：明信片 Postcards、日记 Diary、纪念品 Souvenirs、合影 Photos |

归位：

- Garden 不再是一级标签。庭院是「家」里的一屏。余额不够时，出行页也能看到成熟数量和一键收取。
- Shop 和 Bag 合成出行页。种子、家具先仍可在同页「补给」分段购买；P2-25 再把种子放进阳台、家具放进装饰模式。出行页最终只留食物和护符，完整商店留作兜底，不做一级 Tab。
- Diary 只在收藏页内部分段，不再占底部导航。
- 池塘只保留底部这一个入口。顶栏的 3D 和鱼图标删掉。房间列表里不再出现池塘。2D 池塘房间和 3D 锦鲤池是同一条路径：先进池塘场景，再点「进入 3D 锦鲤池 / Enter 3D Pond」。

从首页到达任一核心功能不超过两层，同一个功能不要留两套入口。旧存档里的房间、物品、相册、日记都还在。

随 P0-11 一起去掉的界面：顶栏 3D、鱼、速度 ×1；房间药丸行；首页纪念品卡；页脚链接那一行；日记上过小的翻页钮。声音、速度、存档导出、设置、隐私、帮助进顶栏「⋯」列表，每行点击区 48pt。

## 顶栏

高 56pt，加在刘海安全区下面。只放四个元素，每个点击区至少 48×48：

1. 标题（团子旅行）
2. 三叶草余额
3. 中 / EN
4. ⋯ 更多

时间、季节、天气不是按钮，放在场景下方的状态文字里，例如 `09:48 · 秋 · 雨 ｜ 团子在家`，字号 12–14pt。

语言：第一次打开跟随系统语言。Capacitor 读 locale。玩家手动切换后记住选择。中英切换留在顶栏，不放进设置深处。

## 尺寸

全站用同一组令牌：

- `--tap-min: 48px`。可点区域至少 48×48（iOS 44pt 与 Android 48dp 里取大的）。图标可以画得小，用 padding 把点击区补满。相邻点击区之间至少 8px。
- 一级按钮高 56pt，次级按钮高 48pt。
- 正文至少 14pt，辅助文字至少 12pt。不再用 21–27pt 高的功能行。
- 底部导航：高 64pt，再加 `env(safe-area-inset-bottom)`。图标约 24px，文字约 12px。文案用上面的短词。
- 顶栏：安全区 + 56pt。
- 场景和按钮不压刘海，也不压底部横条。吸底的主按钮、喂鱼条使用 `bottom: calc(64px + env(safe-area-inset-bottom))`。
- 目标胶囊可以画成 44pt 高，两侧留出间距；点得到的区域仍然至少 48×48。
- 房间列表每一行 52pt。装饰按钮是 48pt 圆形。进入 3D 的主按钮 56pt。池塘全屏时左上返回 48pt。

## 首页（自上而下）

```text
┌─────────────────────────────┐
│ ▓▓ 安全区（刘海）▓▓          │
│ 团子旅行   🍀128   中/EN  ⋯ │  56pt 顶栏
├─────────────────────────────┤
│ ┌─────────────────────────┐ │
│ │      场景大图（客厅）     │ │  约 270pt
│ │  访客气泡     团子·可点   │ │
│ │ ○ ● ○ ○ ○   [客厅 ▾]    │ │  圆点 + 房间名
│ └─────────────────────────┘ │
│ 09:48 · 秋 · 雨 ｜ 团子在家   │  状态行，不是按钮
├─────────────────────────────┤
│ 团子状态卡：刚睡醒，在伸懒腰… │  点卡片展开今日日程
│ ┌─────────────────────────┐ │
│ │  🎒 一键打包出发          │ │  56pt 主按钮
│ └─────────────────────────┘ │
│ [收三叶草 ×8]  [菜熟了 ×2]   │  有内容才出现，48pt
│ 下一目标：明信片 3/13 ›       │  48pt，点去收藏
│ （可滚：访客留言、今日心情签） │
├─────────────────────────────┤
│  家      出行     池塘    收藏 │  64pt + 安全区
└─────────────────────────────┘
```

室内房间的右下角放一枚 48pt 圆形「布置」按钮，只在室内出现。庭院不放这枚按钮。

首页主按钮只有一处，随状态换文案：

| 状态 | 按钮 | 点下去 |
| --- | --- | --- |
| 在家，还没打包 | 一键打包出发 | 打开确认 Sheet，不直接送走 |
| 已打包，还没出门 | 送团子出门 | 确认后出发 |
| 旅行中 | 团子旅行中 · 还剩 2:13 | 打开行程，不另开页面 |
| 已回家 | 团子回来了，开箱 | 进入开箱 |

玩家每次只需要看这一个按钮。

「下一目标」是一行未集满的收集进度，点进收藏。收藏 Tab 用红点表示有新明信片或新纪念品，首页不再堆纪念品卡。

## 房间

手机上换房间只靠手势：

- 左右滑切换：庭院、客厅、读书角、厨房、阳台、门廊。
- 横向滑动和页面纵向滚动做角度锁定。手指位移超过 10px 时，这次手势不触发「点团子」。
- 场景下方是圆点，加上当前房间名胶囊。点胶囊打开房间列表 Sheet，一行一个房间，行高 52pt。有访客或菜熟了时，行上有角标。
- 任一房间最多两次操作到达（滑一次，或点开列表再点一行）。
- 平板和宽屏网页可以留下 ‹ › 箭头。手机上不显示药丸行，也不显示箭头。

## 出行页与确认 Sheet

```text
┌─────────────────────────────┐
│ ‹ 准备出行 Prepare      🍀128│
│ [行囊 Bag] [补给 Shop]       │  页内分段，48pt
├─────────────────────────────┤
│ 为我推荐一组（按右侧目标）     │  48pt
│ 目标：随便走 / 找新地方 / 去远方 / 快点回 │
│ ① 食物（必选）               │
│ 横滑卡，整张可点              │  约 104×120
│ 卡面写时长、库存或价格         │
│ ② 护符（可选）               │
│ 「不带」是一张正式卡           │
│ 提示：此组合偏向森林/稀有，    │
│       该方向日记已集 1/3      │
│ ── 补给（同页下方）──        │
│ 食物 / 护符 / 种子 / 家具     │
│ 点卡片打开详情 Sheet          │
│                  [立即购买]   │  48pt，在 Sheet 里
├─────────────────────────────┤
│ 合计 🍀17 · 余额剩 111 · 1-6h │
│ ┌─────────────────────────┐ │
│ │   打包出发 Pack & Go      │ │  56pt，在导航之上
│ └─────────────────────────┘ │
└─────────────────────────────┘
```

卡片本身就是选择器，不再有单独的小 Buy 按钮。库存为 0 的卡显示价格；选中它不必先买。出发按钮此时写成「买下并打包出发（🍀17）」，一次确认完成购买、打包和出发。合计、余额和预计时长写在按钮上方。

首页主按钮打开的确认 Sheet：

```text
这次这样去？
[艾草团子 1-2h] + [森林护符]     换一组     我自己选
为什么推荐：还没去过的地方优先 · 时长适中 · 最省三叶草
合计 🍀17（出发时购买） · 预计 1-2 小时
[ 就这样出发 ]
```

推荐只用三件事：玩家选的目标胶囊、还没集满的日记、当前余额。这三条理由写在 Sheet 上。「换一组」在同一个目标里轮换组合。「我自己选」进入上面的完整出行页。出发要占 1–6 小时，所以必须经过这个确认，不能点一下就走。

已有库存时，从收取到出发不超过 3 次点击，并且不需要切换 Tab。库存不够时，也是这一次确认里买完再走。

原来的目的地规则说明做在两处，不再单独做一页：组合下面写清偏向和该方向日记进度；收藏里未获得的「?」格子可以点开，显示剪影、地名、稀有度，以及「还没去过 · 日记 0/3」。文字和 `chooseDest` 的实际权重一致。

## 一键做什么，什么留下手动

一键收取：庭院浮出「收三叶草 ×8」。点击后三叶草飞向顶栏余额。幸运四叶草不进这一键，仍要点那一株，并给一个小音效。

草地上按住拖动，可以扫过成熟三叶草连续收取。不想拖的人用一键收取。

一键开箱：回家的包裹是一个整体。打开后依次翻明信片、纪念品进入展示、日记归档，最后点一次「收下全部」。三样东西在动画开始时写入存档。动画放到一半关掉，不丢、也不重复领。

再来一次：开箱结果页和出行页都有，用刚才的组合。库存够就进入确认 Sheet。不够时按钮写出差额，不悄悄换成另一组。

同一类劳动同样处理：阳台「一键收获」「一键种满空地（按推荐）」；锦鲤按住连喂。

这四件事继续手动：

1. 出发时机和时长档。旅行占掉玩家当天的真实时间，不自动出门。
2. 护符和目标。这是去向和花费之间的选择，推荐可以预选，不能直接替玩家定死。
3. 扣三叶草的购买。推荐可以预选物品，扣费必须在确认 Sheet 里写明合计和余额。
4. 装饰摆放。拖拽是玩法。旋转和碰撞仍在 P2-23，留在手动布置里。

长按只用于装饰模式里拖家具，不拿来做必须完成的操作。下拉不赋予刷新。日记卡片可以左右滑翻页，同时保留一对 48pt 翻页按钮和「目录」按钮。

## 激励广告的唯一位置

全游戏只有这一处：出行确认 Sheet 或出行页里，**余额小于本次合计** 时，主按钮下面出现一条次级描边按钮，例如「看视频补三叶草 +30（还差 12）」。

- 玩家点了才播放。
- 播完立刻到账，Sheet 不关闭，接着可以点出发。
- 按钮上写明单次奖励和每日上限。
- 余额够的时候，顶栏、庭院、开箱、池塘都不出现广告。
- 不自动弹出。
- 不和出发按钮合成「看了广告才能走」。
- 教程首旅不出现。首旅用玩家负担得起的组合，或免费组合。

P0-15 把这个位置定下来。P1-07 关掉它时，这里不请求广告，商店里也不再留旧入口。P1-08 才把原生 SDK 接到这一个按钮上。

## 安卓返回键

栈从顶往下：

1. 关掉最上层 Sheet、弹窗或图片查看。
2. 退出 3D 池塘全屏。
3. 退出装饰模式。
4. 当前不是「家」时，回到「家」。
5. 已经在首页时，再按一次退出。

返回键不触发打包、购买或广告。扣三叶草只走正向确认。退出时沿用自动存档，首页不要再弹「确认退出」。

池塘进入 3D 全屏后隐藏底部导航，只留左上 48pt 返回，以及底部吸底条：食物选择 48pt，Feed Koi 56pt。吸底条同样让开导航高度和安全区。这样标签栏不会被挤到画面外面，位置也和其他页一致。

所有 Sheet 用同一组件：上滑打开房间列表、组合确认、物品详情；下滑或点遮罩关闭。

## 手势

| 手势 | 行为 |
| --- | --- |
| 左右滑场景 | 换房间。与纵向滚动锁角度。位移超过 10px 不触发点团子 |
| 点团子 | 摸摸团子（P1-14）：爱心和随机一句台词。轻点判定短于 250ms |
| 在草地上按住拖动 | 连续收取扫过的成熟三叶草。四叶草除外 |
| 日记卡左右滑 | 翻页。另有 48pt 按钮和目录 |
| 下拉 | 无功能 |
| 长按 | 只在装饰模式里拖家具 |
| Sheet 上滑 / 下滑 | 打开或关闭房间列表、确认、物品详情 |

## 宽度

验收四档，中英都要过：

- 宽 360、390、430：主按钮和底部导航单行不截断、不重叠。
- 平板：内容列最大宽 600px，水平居中。底部导航和这一列同宽、一起居中。
- 不另做一套横屏界面。

P0-16 在网页上对照截图。P1-04、P1-06 只在安装包上复验同一套规则。
