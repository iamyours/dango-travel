# 任务板

这是进度的唯一来源。认领、交接和合并时只改本文件里的对应行，不要在别的文档复制一张任务表。

怎么改一行，见 [AGENT_WORKFLOW.md](AGENT_WORKFLOW.md)。每阶段要做成什么样，见 [ROADMAP.md](ROADMAP.md)。

基准代码：`main@2cad3db`（2026-11-04）。说明里的「现状」指这个提交，避免把已经有的功能重做一遍。

## 怎么读这张表

- **ID** 稳定不变。新增任务用该阶段下一个编号，不要重排旧 ID。
- **状态** 只能是：`待认领`、`进行中`、`待评审`、`已完成`、`阻塞`。
- **阻塞** 时，状态列仍只写 `阻塞`。原因写在说明开头，格式为 `阻塞原因：…`。
- **负责人** 空着表示没人认领。不要填「无」。
- **更新时间** 用 `YYYY-MM-DD`。待认领时留空。
- **依赖** 写任务 ID，多个用逗号加空格。列出的每一项都要是 `已完成` 才能开工。没有依赖时写 `无`。
- **难度** 只用：`低`、`低-中`、`中`、`中-高`、`高`、`外部`。`外部` 不计入开发估算。
- 单元格里不要写竖线 `|`。
- 新增玩家可见文案：同时改 `assets/i18n/zh.js` 与 `assets/i18n/en.js`，禁止新增硬编码中文。内容类任务下面用「文案：zh+en」提醒，验收仍以这条为准。
